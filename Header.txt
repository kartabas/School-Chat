								School Chat

Це шкільний чат в якому можна підключити свій клас, і переписуватись з іншими учнями школи .
Є режим глобального чата самої школи ,і також анонімний але в місяць прийдеться платити 5 євро в рік 48 євро підписки.
Є свій профіль зі досяжностями ,і рейтинг класів які самі активні , і також хтось може постити новини на сайті для цієї школи .

-використовувати мемні гифки для валідації

// Історія комітів
git hist

// Откат кода на github repository
git push -f origin  9756c39:main

// Откат кода на localhost
git reset --hard 9756c39


//Слить branch з main

git checkout master
git pull origin master
git merge test
git push origin master
